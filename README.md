# 加班记

一个本地离线的 Android Compose 加班统计 App。

## 已实现

- 一次“结束加班”打卡，工作日默认从 18:00 起算。
- 凌晨 06:00 前自动归属前一天。
- 周末默认从 09:00 起算，可在设置中修改。
- 补卡、跨天、编辑、删除和重叠检查。
- 自动排除周一至周五 09:00-18:00 正常工作时段。
- 支持补班、休息日和全天加班等特殊日期。
- 按月统计总小时、标准工作日、工作日/休息日和每日图表。
- 使用系统文件选择器导出 UTF-8 CSV，无需存储权限。
- 可补录某天加班，并为每条记录添加最多 4 张工作证明照片。
- 内置水印相机，实时显示经纬度；横竖屏旋转后水印始终位于左下角。
- 经纬度和拍摄时间会写入照片像素，并保留 EXIF 坐标信息。
- 可按全部记录或指定月份导出 Excel，照片会嵌入表格。
- 首次安装导入 2026 年 7 月现有的 18 条记录。

## 正确统计口径

18 条原始记录合计为 130.5 小时。排除 7 月 6 日 09:00-18:00 的正常工作区间后，应计加班为 121.5 小时，按 8 小时折合 15.1875 天，界面显示 15.19 天。

## 开发环境

- JDK 17
- Android Studio 或 Gradle 8.14.5
- compileSdk / targetSdk 36
- minSdk 26
- Kotlin 2.2.21
- Compose BOM 2026.06.00
- Lifecycle 2.9.4（API 36 / AGP 8.13 兼容版本）
- Room 2.8.4
- CameraX 1.6.1

## 构建

```bash
./gradlew assembleDebug testDebugUnitTest
```

APK 输出位置：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 数据说明

所有记录和设置都保存在设备本地。首次数据只导入一次；用户清空数据后，重启 App 不会自动恢复旧记录。
